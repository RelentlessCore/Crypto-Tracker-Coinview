# 💹 CryptoPrice Tracker

A **powerful, real-time cryptocurrency price tracking platform** built with **React and the CoinGecko API**, delivering dynamic coin insights, predictive search, interactive historical charts, and live market data in USD and EUR. Designed with performance and clarity in mind, this app offers a fast, responsive, and intuitive user experience across all devices.

---

## ✨ Features

✅ **Live Market Data** – Real-time prices, market caps, and 24h changes for top cryptocurrencies  
✅ **Dynamic Coin Pages** – Detailed views with current stats and price history charts  
✅ **Currency Switching (USD/EUR)** – Instantly toggle between supported currencies  
✅ **Predictive Search** – Intelligent autosuggestions as you type  
✅ **Interactive Line Charts** – Visualize 10-day historical pricing with Google Charts  
✅ **Responsive UI** – Clean layout and mobile-friendly design  

---

## 🔥 Tech Stack

- **Core:** HTML, CSS, JavaScript  
- **Frontend Library:** React  
- **Routing:** React Router  
- **API Integration:** CoinGecko API  
- **Data Visualization:** Google Charts  
- **State Management:** React Context API  
- **Bundler:** Vite
